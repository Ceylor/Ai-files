# 🤖 Самообучение на примерах (Модуль 7)

> Ключевая фича AI AutoClip Pro 2.0: система **учится на ваших готовых клипах**,
> извлекает «паттерны успеха» и применяет их к новым видео. С каждым новым
> примером она становится умнее — это **непрерывное обучение**.

---

## 🎯 Что делает модуль

Вы скидываете готовые клипы, разбитые по категориям (например, «путешествия»,
«спорт», «туториалы», «реакции»). Система анализирует каждый клип и извлекает
**5 слоёв паттерна успеха**:

| Слой | Что анализирует | Источник |
|------|-----------------|----------|
| 🎞 **Структура** | положение хука, число фаз, длительность | content-based детекция сцен |
| ⏱ **Темп** | средняя длительность склейки, склейки/мин, метка (fast/balanced/slow) | детекция сцен |
| 🎚 **Переходы** | число переходов, средняя длительность | детекция сцен |
| 🎨 **Цветокоррекция** | яркость, насыщенность, контраст, температура | OpenCV HSV-сэмплы кадров |
| 🎵 **Музыка** | BPM, энергия %, тональность (Camelot) | `audio_analyzer` (librosa) |

Каждый паттерн имеет **компактный вектор признаков (10 измерений)** для быстрого
поиска похожих стилей.

## 🏗 Архитектура

```
src/modules/mod7_learning/
├── __init__.py              # публичный API модуля
├── pattern_models.py        # Pydantic-модели (EditPattern, профили)
├── pattern_extractor.py     # извлечение паттернов из клипов
├── vector_store.py          # векторное хранилище (FAISS → Chroma → NumPy)
└── learner.py               # оркестратор LearningEngine
```

### Векторное хранилище (graceful-fallback)

| Приоритет | Бэкенд | Когда используется |
|-----------|--------|--------------------|
| 1 | **FAISS** (`IndexFlatIP`) | если установлен `faiss-cpu` |
| 2 | **ChromaDB** (`PersistentClient`) | если установлен `chromadb` |
| 3 | **NumPy** (in-memory cosine) | всегда доступен (дефолт) |

Persist-данные хранятся в `data/learning_store/` (`patterns.json` + `vectors.npy`)
и переживают перезапуск — **опыт накапливается непрерывно**.

> Установка опциональных ускорителей:
> ```bash
> pip install ".[faiss]"   # быстрый поиск
> pip install ".[chroma]"  # персистентное хранилище с метаданными
> ```

## 🧠 Алгоритм самообучения

```
1. ЗАГРУЗКА     — клипы по категориям → data/reference_clips/<категория>/
2. ИЗВЛЕЧЕНИЕ   — для каждого клипа извлекаем EditPattern (5 слоёв + вектор)
3. ВЕКТОРИЗАЦИЯ — считаем 10-мерный вектор признаков (нормализация в [0,1])
4. СОХРАНЕНИЕ   — вектор + метаданные в векторное хранилище (persist)
5. ПРОФИЛЬ      — агрегируем все паттерны категории в единый «средний» стиль
6. ПРИМЕНЕНИЕ   — новый клип монтируется в стиле агрегированного профиля
   (и/или ищем самый похожий паттерн через find_similar)
```

## 🚀 Как использовать

### Через REST API (FastAPI)

```bash
# 1. Запустить сервер
uvicorn src.api.main:app --host 127.0.0.1 --port 8000

# 2. Загрузить референсы категории "travel"
curl -F "category=travel" -F "files=@clip1.mp4" -F "files=@clip2.mp4" \
     http://127.0.0.1:8000/api/upload_references

# 3. Запустить самообучение
curl -X POST -F "category=travel" http://127.0.0.1:8000/api/learning/train

# 4. Статус обучения
curl http://127.0.0.1:8000/api/learning/status
# => {"store_backend": "numpy", "total_patterns": 2, "categories": ["travel"]}

# 5. Агрегированный профиль стиля категории
curl http://127.0.0.1:8000/api/learning/profile/travel

# 6. Похожие паттерны
curl "http://127.0.0.1:8000/api/learning/find_similar/travel?k=3"
```

### Через Python

```python
import asyncio
from src.modules.mod7_learning.learner import LearningEngine

async def main():
    engine = LearningEngine("data/learning_store")
    # Обучение по папке референсов категории
    patterns = await engine.learn_from_references("data/reference_clips/travel", "travel")
    # Профиль стиля
    profile = engine.get_category_profile("travel")
    # Поиск похожих
    hits = engine.find_similar(profile, category="travel", k=3)
    print(hits)

asyncio.run(main())
```

## 📌 Интеграция с пайплайном

Агрегированный профиль категории (`EditPattern`) в дальнейшем передаётся
в нарративный движок и редактор как параметр стиля: темп, ритм склеек,
цветокоррекцию и предпочтительную музыку. Это позволяет монтировать новые
клипы **в стиле ваших лучших примеров**.
