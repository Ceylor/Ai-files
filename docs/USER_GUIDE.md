## Установка и запуск

### Требования
- **Windows 10/11** (скрипты запуска — `.bat`).
- **Python 3.9+** (скачать: https://www.python.org/downloads/ — обязательно поставьте галочку «Add to PATH»).
- **Node.js 18+** (скачать: https://nodejs.org/ — LTS-версия).
- **FFmpeg** (для работы с видео). Если его нет — скрипт `run_dashboard.py` скачает автоматически.

### Шаг 1. Скачайте репозиторий
```bash
git clone <адрес-вашего-репозитория> ai-autoclip
cd ai-autoclip
```
Или скачайте ZIP-архив и распакуйте в удобную папку.

### Шаг 2. Установите зависимости
Запустите двойным кликом файл:
```
install_deps.bat
```
Что он сделает автоматически:
- создаст виртуальное окружение `venv`;
- установит Python-библиотеки (`pip install -r requirements.txt`);
- установит зависимости фронтенда (`npm install` в папке `frontend`).

Дождитесь надписи **«Installation finished!»** и закройте окно.

### Шаг 3. Запустите систему
Запустите двойным кликом файл:
```
start_all.bat
```
Система поднимется в одном окне:
- **Бэкенд** (FastAPI) — `http://127.0.0.1:8000`;
- **Фронтенд** (Next.js) — `http://localhost:3000`.

Логи пишутся в папку `logs/` (не мешают, автоматически игнорируются git).

> Браузер открывается **не автоматически** — откройте его вручную и перейдите по адресу ниже.

## Первый вход

1. Откройте браузер и перейдите на **http://localhost:3000**.
2. Вы попадёте на **Дашборд** — главную страницу со статистикой:
   - **Всего видео** — сколько видео зарегистрировано в системе;
   - **Клипов готово** — сколько клипов уже создано;
   - **Композиций** — количество собранных композиций;
   - **Активных задач** — сколько задач сейчас обрабатывается.

   Ниже — график «Распределение по статусам» и «Прогресс задач», а также список
   последних задач.

3. Слева — боковое меню с разделами: **Дашборд, Задачи, Результаты, Категории, Обучение, Настройки**.
4. Внизу меню — переключатель **светлой/тёмной темы**. Выбор сохраняется автоматически.

## Загрузка видео и создание задачи

Обработка видео происходит через **пакетные задачи** — вы указываете папку на сервере,
в которой лежат исходные видео, и система обрабатывает их все.

### Пошагово
1. Положите исходные видео (`.mp4`, `.mov`, `.avi`, `.mkv` и др.) в папку на компьютере/сервере.
2. Перейдите во вкладку **«Задачи»**.
3. В блоке **«Загрузка папки»** укажите путь к папке с видео, например:
   ```
   C:\MyVideos\Trip
   ```
4. Нажмите кнопку **«📂 Сканировать папку»**.
5. Система найдёт видео и создаст задачу — появится сообщение вида:
   ```
   ✅ Задача #3 создана. Найдено видео: 12, зарегистрировано: 12.
   ```
6. В списке задач найдите свою задачу (по номеру `#`) и нажмите **«Детали →»**.
7. Нажмите **«▶️ Запустить обработку»** — начнётся автоматический монтаж.

> 💡 Обработка идёт в фоне. Вы можете спокойно перейти на другие вкладки
> или закрыть страницу — процесс не остановится.

## Отслеживание прогресса

Во вкладке **«Задачи»**:

- **Список задач** показывает статус каждой:
  - 🟡 **В очереди** (`pending`) — задача создана, ещё не запущена;
  - 🔵 **Обработка** (`processing`) — идёт монтаж;
  - 🟢 **Готово** (`completed`) — все видео обработаны;
  - 🔴 **Ошибка** (`error`) — что-то пошло не так.

- В **деталях задачи** (кнопка «Детали →») видно:
  - **прогресс-бар** с процентом выполнения;
  - счётчик «обработано/всего»;
  - список видео с их индивидуальными статусами.

- Обновление автоматическое (каждые 3 секунды), плюс есть кнопка **🔄**.

- Подробные логи работы видны в папке `logs/` (файлы `backend.log`, `frontend.log`).

## Результаты

Готовые клипы появляются во вкладке **«Результаты»**.

Что можно делать:
- **Просматривать** видео прямо на странице (встроенный плеер);
- **Смотреть таймлайн** под каждым клипом — цветные сегменты сцен и маркеры переходов;
- **Скачать** клип — кнопка **«⬇️ Скачать»**;
- Фильтровать: **Все / Клипы / Композиции**;
- Смотреть технические данные — кнопка **«Анализ»** (JSON-метаданные).

> В результатах появляются записи со статусом **«Готово»** (отдельные клипы)
> и **«Композиция»** (собранные из нескольких клипов ролики).

## Обучение системы

Система умеет **самообучаться** на примерах — если загрузить в категорию референсные
клипы и запустить обучение, она запомнит стиль (темп, переходы, цветовую гамму) и будет
применять его при монтаже.

### Шаг 1. Создайте категорию
1. Перейдите во вкладку **«Категории»**.
2. В блоке «Новая категория» введите **название** (например, `Путешествия`) и при желании описание.
3. Нажмите **«➕ Создать»**.

### Шаг 2. Загрузите референсные клипы
Референсы — это готовые клипы, стиль которых вы хотите скопировать. Положите их в папку
`data/reference_clips/<название_категории>/` на сервере (например,
`data/reference_clips/Путешествия/`).

### Шаг 3. Запустите обучение
1. Перейдите во вкладку **«Обучение»**.
2. В блоке «Запустить обучение» выберите категорию из списка.
3. Нажмите **«🧠 Запустить обучение»**.
4. Статус обучения и список обученных категорий появятся ниже.

> ℹ️ Подробнее о механизме самообучения — см. [`ARCHITECTURE.md`](ARCHITECTURE.md) (модуль `mod7_learning`).

## Настройки

Во вкладке **«Настройки»** можно изменить параметры обработки:

- **Макс. длительность клипа (сек)** — ограничение длины готового клипа;
- **Порог схожести для композиции** — насколько похожие видео объединять в композицию;
- **Макс. фрагментов в кластере** — сколько кусков максимум в одном клипе;
- **Категория по умолчанию** — категория для новых видео.

Нажмите **«💾 Сохранить»** — настройки сохранятся в браузере (localStorage).

## Устранение неполадок

### «Порт 8000 или 3000 уже занят»
- Закройте другие программы, использующие эти порты.
- Или смените порт в `start_all.bat` (параметры `--port 8000` и `dev` для фронтенда).

### «Virtual environment not found» / «node_modules not found»
- Вы не запустили `install_deps.bat`. Запустите его один раз.

### Фронтенд открывается, но данные не грузятся (пусто)
- Убедитесь, что бэкенд запущен на `http://127.0.0.1:8000`.
- Проверьте логи в `logs/backend.log`.

### Видео не находится при сканировании папки
- Убедитесь, что путь указан **без кавычек** и существует.
- Папка должна содержать видео с поддерживаемыми расширениями (`.mp4`, `.mov`, `.avi`, `.mkv`, `.webm`, `.m4v`).

### «FFmpeg не найден»
- Установите FFmpeg вручную (https://ffmpeg.org) и добавьте в PATH,
  либо запустите `python run_dashboard.py` — он скачает FFmpeg автоматически.

### Проблемы с темой (светлая/тёмная)
- Выбор темы хранится в `localStorage` браузера.
- Если тема «сломалась» — очистите кэш сайта (Ctrl+Shift+Del → «Кэшированные изображения и файлы»)
  и обновите страницу. По умолчанию включена тёмная тема.

### Ошибка в логике обработки (красный статус `error`)
- Откройте логи `logs/backend.log`, найдите строку с `❌` или `ERROR`.
- Чаще всего проблема — отсутствие FFmpeg, Ollama или свободного места на диске.

### Нет доступа к интерфейсу вообще
- Проверьте, что оба процесса живы (окно `start_all.bat` не закрыто).
- Попробуйте открыть `http://127.0.0.1:8000` (бэкенд) — если работает, значит дело во фронтенде.
